size_t  password_len 
)

Read WiFi SSID and password saved in NVS by WiFiManager.

This function reads the WiFi credentials from the standard NVS namespace used by ESP32 WiFi stack (nvs.net80211).

Parameters
ssidBuffer to store the SSID (must be at least 33 bytes)
ssid_lenSize of the SSID buffer
passwordBuffer to store the password (must be at least 65 bytes)
password_lenSize of the password buffer
Returns
esp_err_t ESP_OK on success, error code otherwise
  • ESP_ERR_INVALID_ARG: Invalid parameters
  • ESP_ERR_NVS_NOT_FOUND: SSID or password not found in NVS
  • Other ESP error codes from NVS operations
